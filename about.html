About me

Why I chose IT, and where I'm going

A little about my path into technology, what I'm working toward, and the skills I'm currently building.

Why Information Technology?

I chose IT because I've always liked figuring out how things work, and then figuring out how to make them work better. What pulled me toward software specifically was realising that code is a way of turning logic into something useful — a program that actually helps someone register, log in, or send a message. I like that IT rewards patience and precision as much as creativity.

Career goals

I'm working toward a career as a software developer, ideally building applications that people use every day. Right now that means mastering the fundamentals — Java, object-oriented programming, and clean problem-solving — before specialising further as I move through my studies. I'd also like to gain real workplace experience through an internship in the next year or two.

Interests within IT

Application development is my main interest — I like the process of taking a set of requirements and turning them into a working program with proper validation and structure. I'm also curious about how networks and infrastructure work underneath the applications I build, which is part of why I've enjoyed my computer networking coursework alongside programming.

Skills I'm developing

I'm actively building my skills in Java and object-oriented design, input validation and regular expressions, using Git and GitHub for version control, and writing code that's organised and easy to follow. I'm also working on my debugging process — learning to read an error properly before trying to fix it.
