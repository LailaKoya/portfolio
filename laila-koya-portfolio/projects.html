QuickChat — Java Console Chat Application

A Java console application built for my Programming module (POE). Users register with a validated username, password, and South African cell number, then log in to send, store, search, and delete messages. Every rule is enforced with custom validation logic and regular expressions, and each message is given a unique hash for tracking.

Healthcare Facility Network Design

A Computer Networks assignment analysing and redesigning the network for a healthcare facility. I motivated a move from a peer-to-peer setup to a client-server model for better security and reliability, diagnosed a connectivity fault using the OSI model, and proposed a cabling and IP addressing plan — fibre optic for the server backbone, Cat6 for endpoints, with a structured private IP scheme for every device.
